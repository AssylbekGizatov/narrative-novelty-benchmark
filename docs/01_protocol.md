# Protocol fixed before main experiment execution

Date: 2026-11-15. This is a computational measurement study, not a participant study or an estimate of an LLM treatment effect. Earlier four-case demonstrations are development material, excluded from reported sample sizes. The manuscript must not describe external games as the present author's creations.

## Questions
1. Which asset-based, rollout-based and aligned transition measures detect controlled changes to player-action consequences?
2. Which changes are mistaken for loss by endpoint, branch-count and whole-path measures?
3. How sensitive are results to consequence representation and finite rollout coverage?

## Materials and sampling
Two complete MIT-licensed stories in inkle/ink-library at commit aee1e57ceacefcea40830dfa2bc15c7d96e6c95b: The Intercept and LD41 Emoji (title: alarm-clock emoji; author Pat Scott). Use the official inkjs 2.3.2 compiler/runtime, not a regex-based approximation of Ink control flow. Both are convenience cases, not a representative sample of games or independent authors.

Sample 200 uniform-choice playthroughs per story with reproducible seeds and a 120-choice horizon. Select at most 120 distinct branching save states per game by seeded reservoir sampling; report eligibility, coverage and truncation. Evaluate every available choice from each retained state via state restoration. Store action source paths, text, resulting text, changed global variables, next choices and terminal status. Consequence identity is an explicit observable proxy, not a human judgment of meaning.

## Treatments
On the extracted local transition records: identity; typography-only rewrite; duplicate option aliases; option reordering; removal of choices; collapse of distinct consequences; permutation of action-consequence assignments. Structural mutations retain text-asset inventory. This is an evaluation-layer stress test, not a claim that modified full games are coherent. Doses: 0.25, 0.5, 1.0 of eligible choices; five fixed seeds per structural mutation. Record the realised intervention and skip invalid or unchanged mutations explicitly. Never select only cases where the proposed metric succeeds.

## Metrics
Asset word-set Jaccard; asset character-trigram Jaccard; asset TF-IDF cosine; paired-choice rendered-response word Jaccard; aligned transition-set Jaccard; transition retention; relative unique-consequence loss. Report modality-sensitive and order-sensitive controls. Neither transition difference nor retained breadth alone establishes originality.

## Criticism and additional checks
Use procedural finite DAGs only as a separately labelled stress suite: reconvergence, delayed consequences, duplicate options, and one-change saturation of exact full-path matching. Test noisy semantic labels and finite sampling. Analyse per game; no population claim from two games. Any post-protocol changes must be recorded in the audit log, not silently relabelled preregistered. This timestamped protocol is not an independent preregistration.

## Reporting
All numbers must be generated by executable scripts. No invented authors, players, judges, model generations, p-values, novelty annotations or model comparisons. Publish negative controls, exclusions and counterexamples. AI-assisted research and writing provenance is disclosed. The deliverable is a complete methodological paper draft, with empirical authoring-effect validation explicitly outside completed scope.
