# Adversarial audit and decision log

This log records weaknesses found during development, including results that oppose the initial framing. The study is a single AI-assisted research workflow; this is not an independent peer review.

1. **Four hand-built examples are insufficient.** Replaced them as the main evaluation with runtime-extracted decisions from two published, licensed stories. Kept separate procedural counterexamples for properties with exact answers. Neither intervention counts nor save-state counts are a count of authors or games.
2. **Static Ink regex parsing is unsound.** Ink has variables, conditions, stitches, tunnels and visit counts. Use inkjs compiler/runtime with saved states; replay every extracted transition independently.
3. **An error is not an ending.** Initial extraction failed on an unhandled runtime ending. Added explicit error collection. Report 64 error-terminated Intercept walks rather than silently treating them as story endings; exclude six sampled contexts with at least one erroneous successor. No source-game bug is repaired behind the reader's back.
4. **Asset inventory is an intentionally weak baseline.** Rewiring preserves it by construction. Add paired-choice response baselines and Unicode character trigrams. Do not claim they are all defeated.
5. **The strong textual baseline challenges our premise.** It detects all eligible prose mutations in this sample. Therefore, the claim must be about evaluated units and representations, not universal superiority of graph over text metrics.
6. **Unicode matters.** Every Emoji successor response has an empty word-token set under the documented tokenizer. A 0 score cannot be interpreted as narrative identity. Character trigrams provide a modality control.
7. **Change is not loss.** Permutation preserves consequence support, so outcome loss is exactly zero even when aligned transition distance is large. Report distance and signed breadth loss separately.
8. **Perfect structural sensitivity is algebraic.** Eligibility is defined by changed aligned pairs. A nonzero Jaccard distance is guaranteed and is not predictive accuracy, validation of originality or an empirical discovery about AI.
9. **Opaque labels are an oracle.** Aligned consequence identities are carried through designed edits. They are not automatically inferred semantic equivalence classes. Typographic invariance under frozen labels is designed, not a learned paraphrase capability.
10. **Whole-path equality overreacts.** A one-state edit can change every full path while affecting few local transitions. Added six analytical chain tests; report this failure of the earlier exact-trajectory idea.
11. **One-step signatures miss delayed consequences.** Added 30 explicit horizon/delay conditions. The real-game study measures immediate observables, not all future possibility.
12. **Terminal/nonterminal is too coarse.** It cannot distinguish many consequences. It is an ablation, never an ending-identity gold standard.
13. **A single next-action path ID is not a story state.** Consequence signatures combine rendered output, changed global variables, available next action locations and terminal status. Hidden visit histories can still differ; this abstraction can merge future-distinct histories.
14. **Uncertainty does not create a population.** Context bootstrap bands are conditional stability summaries. Two selected games do not support industry-wide effects or cross-author generalization. Rows across seeds/doses share contexts.
15. **Shared noise seeds accidentally correlate masks.** Before final reporting, changed the annotation-noise stress test to independent context-hash seeds and 100 replicates per context/rate. This is a disclosed post-protocol implementation correction, not a new preregistered claim.
16. **Finite coverage can invent loss.** Simulate two independent samples from the same two-outcome game and report false directional loss. No novelty interpretation is attached to Monte Carlo states.
17. **No LLM treatment has been tested.** The mutations are deterministic experimental manipulations, not observed AI edits. The completed paper is an instrument audit for future co-authoring studies. No participant or model-evaluation data is fabricated.
18. **A literature catalogue is not our result.** Prior work belongs in Related Work; the abstract and results describe the executed computational study. Bibliographic claims are source-specific, not a claim of an exhaustive systematic review.
19. **DiGRA is not one uniform length rule.** The Central Asia CFP currently specifies 150–300-word abstract submissions, with later papers by invitation. The international conference says 5,000–7,000 words; a requested ten-page compact manuscript is not automatically compliant with that separate track. The template itself has conflicting margin metadata/text; follow its explicit written instructions and document that choice.

20. **Execution and distribution must be honest.** The managed host rejected both TCP and IPC Jupyter sockets. Notebook cells were instead genuinely executed in-process with IPython display capture, and their metadata records this. Four large row-level files were losslessly compressed after analysis; decompression was verified byte-for-byte and hashes preserved. These are delivery changes, not new observations.
